# Helpful things for C++

## Compiling on a Mac terminal 

Usually, this will suffice: 
``` 
c++ hello.cpp -o hello
``` 
But there are a few options for consideration

`-std=c+17` - which version to use 

`-Wall` - keep common warnings 

`-g` - include debugger 

`-O2` - optimize the build
